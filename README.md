# Roomy for Windows

Installers and automatic-update files for [Roomy](https://github.com/keethesh/roomy-releases/releases/latest), a local-first disk-space analyzer for Windows.

Download the latest installer from [Releases](https://github.com/keethesh/roomy-releases/releases/latest):

- `Roomy_<version>_x64-setup.exe` for most Windows PCs (Intel/AMD)
- `Roomy_<version>_arm64-setup.exe` for Windows on ARM

Each installer has a `.sha256` checksum next to it. Scanning happens entirely on your PC.
